# Foldsnap · 留档

Foldsnap combines “folder” and “snapshot”: keep recoverable versions of the folders you choose. 中文名为「留档」，标语为「留一份过去，安心向前」。

## Visual identity

Deep forest green, warm ivory, and three protected archival cards. The layers represent recoverable versions; the curved cradle suggests preserving them. The macOS icon uses soft depth; the web and template menu-bar marks use a simple silhouette for small sizes.

Source assets and generation provenance: [assets/brand](../assets/brand/README.md). Native icon variants are generated by the packaging script, and the menu-bar symbol is a macOS template image so it adapts to light/dark appearance.

## Compatibility

Foldsnap was previously named LocalBackup. This is a presentation change, not a storage migration. Keep the following stable:

- Bundle identifier: `app.localbackup.mac`.
- Private data: `~/Library/Application Support/LocalBackup`.
- Diagnostic logs: `~/Library/Logs/LocalBackup`.
- Repository root and restore-output namespace: `LocalBackup`.
- Background agent identifier, internal CLI executable and module names.

Do not rename any real repository or rewrite stored plan bindings for branding. The native launcher accepts both the new and legacy startup message prefixes so it can attach to an existing service. The package now produces `Foldsnap.app` and `Foldsnap-macOS.zip`; quit a running old instance before switching applications.

Initial name searches are preliminary project research, not a trademark clearance. Public repository: https://github.com/jiyiiang/foldsnap.

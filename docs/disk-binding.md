# 硬盘绑定与插入自动备份（0.8.0）

选择目标目录并保存计划时，后端记录文件系统卷 UUID、挂载根目录及卷内相对路径。绑定数据保存在 SQLite 的计划中；不以磁盘名称、disk2 等临时设备编号或 USB 接口作为身份。存储空间页合并实时卷发现和已保存的目标绑定，离线时仍显示卷 UUID、关联计划和自动触发状态。APFS 的系统卷和 Data 卷具有不同 UUID，分别识别。

## 使用

1. 接入硬盘，在备份计划中添加该盘上的目标目录，保存后即可看到卷 UUID。
2. 开启计划的「自动备份」及「磁盘连接时备份」。
3. 可以在同一计划绑定 A、B 两块轮换硬盘。连接 A 时仅对 A 生成备份；连接 B 时仅对 B 生成备份，不要求两块盘同时在线。每个目标继续保留独立历史和当前视图。
4. 在「存储空间 → 硬盘与计划绑定」查看状态，点击关联计划进入编辑。开关和调度参数可在目标离线时保存；新增/重新绑定目标仍须在线验证。

硬盘改名、挂载名称冲突（例如 `/Volumes/Backup 1`）或更换接口后，按 UUID 重新定位，再使用卷内相对目录。不同硬盘即使名称相同，也不会替代已绑定的 UUID。格式化后的卷 UUID 通常改变，需要重新选择目标；新硬盘也需首次添加绑定。克隆出相同 UUID 的卷不应同时使用，当前不提供硬件序列号去重。

## 调度与安全

- 服务需保持运行；macOS 原生挂载目录事件唤醒检查，另有定时检查兜底。服务启动时对已连接的启用目标执行一次连接检查，可补上应用未运行时插入的盘。
- 检查每个目标的在线状态，持久化待处理插入事件。另一个任务正在运行、排队或暂停时，不丢弃第二块盘的待处理触发。对同计划的待执行任务继续合并，完成后再处理其他待连接目标。
- 每次观察到离线到在线转换，生成一次对应目标范围的任务；连续在线检查不重复运行。离线时清除尚未入队的插入标记，重连后重新产生。事件间极快的拔插可能被系统合并；此时需要后续离线/在线观察或重启服务重新检查。
- 队列持久化完整计划及运行记录的 `destinationIds`，执行前仍比较完整计划是否变化，再应用后端生成的目标范围。HTTP `RunRequest` 不接收该字段，手动运行和预览继续针对全部启用目标。
- 插入任务只针对所记录的绑定目标；拔盘后等待原 UUID，不会改投另一块新接入盘，也不会创建缺失挂载点。若单目标写入过程中断开，当前任务失败且不发布未验证版本；重连可以产生新任务。
- 镜像删除继续要求新预览及逐次明确确认，插入触发不会授权删除。定时/文件变化触发维持原有全部目标在线语义。
- 已完成文件会再次校验，仓库 UUID 校验和源/目标重叠保护继续生效。

## 验证边界

自动测试覆盖独立目标转换、轮换、重复观察、忙队列中的第二次插入、离线绑定保留、同名不同 UUID、改名的发现合并、服务端范围限制、HTTP 注入拒绝、调度离线修改与真实 rsync 单目标发布。开发机未连接测试外置盘，实际硬件拔插、休眠唤醒和异常断电仍需外置盘验收；目录离线模拟不等同于硬件测试。

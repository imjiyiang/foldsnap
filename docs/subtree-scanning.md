# 变化子树扫描（0.13.0）

开启文件变化触发且 macOS 原生监听健康时，APFS 源扫描可以只访问变化项的父目录子树。祖先目录只刷新自身元数据，不枚举未变化的兄弟目录。删除与移动同时更新旧、新路径；目录变成符号链接时记录链接，绝不沿链接遍历。没有脏路径的源可直接沿用完整索引。

进入此模式需同时满足：源路径和物理根身份、卷 UUID、文件系统、完整筛选策略一致；有一小时内完成的完整扫描；源根包含在当前可信原生监听范围；全部源投影与事件队列通过 HMAC 校验。投影签名覆盖完整有序路径集合与条目内容，事件签名覆盖游标/根与全部脏路径，能发现行缺失或修改。使用数据目录内权限 0600 的 fingerprint-integrity.key；密钥丢失/不可用时不使用这种复用。这不是备份加密，也不防持有密钥者回滚整份有效数据库。

根事件、根级路径、事件丢失、挂卸载、监听配置变化、规则变化、不可靠文件系统、损坏/缺失索引、缺少监听覆盖、未来或过期完整扫描时间均回退全扫。按相对修改日期筛选的源始终全扫，防止时间流逝改变选择却没有文件事件。最长间隔检查与每小时完整审计强制重读内容，不使用指纹缓存。轮询后端保持完整遍历。

扫描提交采用新代次，并核对部分扫描沿用的基线代次未被其他扫描替换；冲突自动重做全扫。事件在备份开始前取修订基线，仅在成功后确认不晚于基线的事件；扫描/备份期间的新事件继续保留。事件队列签名无效时先给所有已启用变化计划登记完整重扫，再建立新的可信队列。取消不会发布半份索引或恢复点。

预览显示实际访问路径数和沿用路径数，设置展示上次完整/子树扫描及访问数量。沿用路径不计为重新计算哈希、指纹命中或读取字节数。旧运行缺少这些指标时显示未知或零沿用。

此优化减少文件系统目录枚举；当前仍加载并认证完整 SQLite 投影、构建完整目标视图和更新完整路径集合，因此数据库/内存/签名开销仍为 O(N)。传输使用完整选中文件清单，发布前保持完整目标内容和结构校验。运行中的源不具备文件系统时间点快照语义；原生事件是变化提示，后续事件与定期审计继续收敛。尚未宣称百万文件或 500GB 性能达标，真实外置硬盘拔插和断电验证也仍待完成。

本机隔离实测使用 128 个文件、4 个目录：首次访问 132 个路径；可信空闲预览访问 0、沿用 132；原生事件修改 hot/deep/0.txt 后访问 66、沿用 66，只重算该文件 32 B 内容，其他 63 个文件指纹命中。随后实际执行、完整 manifest 和新文件 SHA-256 均通过。该数据只证明分支访问范围，不能外推大规模性能。另补齐系统 openrsync 深层目录 --link-dest 预演所需的临时目录骨架，预演后重新审计历史快照以确保其内容未改动。
